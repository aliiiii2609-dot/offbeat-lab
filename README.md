# OFF/BEAT · the rhythm audit 🔊

Everyone claims they have rhythm. Prove it.

A one-file rhythm game tribute to OFF/BEAT Studios. Tap when the ring hits the circle. The synthesized bass-heavy track speeds up every 16 beats and adds layers (kick → bass → snare → arp). Three strikes and you're out.

- **Judgments**: PERFECT (±75ms) / clean (±160ms) / OFF BEAT
- **Combo multiplier** with toasts (SHEESH → BOLDER FR → ABSOLUTE CINEMA)
- **Ranks**: from "off beat (derogatory)" to "GROW BOLDER AWARD 🏆"
- **One more thing…**: a hidden typewriter pitch
- All audio synthesized live with WebAudio. Zero dependencies, zero build step.

## Run

Open `index.html`. That's it.
